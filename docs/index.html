What the package does

Create and edit images, apply morphology and binarization, and work with page layouts. The Pascal units load Leptonica functions at runtime. No OpenCV library or CrossVision package is required.

The library has its own release process. It does not need to wait for CrossPascal's model support to be complete.

Using the library

Add pascal/ to your project's unit search path. The Delphi package requires the RTL.

Your application needs leptonica-1.87.0.dll. Place the matching Win64 DLL beside the executable. Pass its full path to LeptInitialize.

The binding calls Leptonica directly through its C API.
