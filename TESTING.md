# Example check

Build LeptonicaHello for Windows x64 with Delphi 13.2 or Lazarus 4.8 and FPC 3.2.2. Follow [INSTALL.md](INSTALL.md) to build the native library and run the example.

The example prints its library path and writes a 256 × 96 grayscale gradient. Open the PNG in an image viewer to inspect it. This check covers image creation and PNG output.
