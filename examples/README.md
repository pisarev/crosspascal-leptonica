# LeptonicaHello

Open `LeptonicaHello.dproj` in Delphi 13.2 or `LeptonicaHello.lpi` in Lazarus 4.8 with FPC 3.2.2. Build for Windows x64. The library belongs at `../bin/leptonica-1.87.0.dll` relative to the project directory. See [the installation guide](../INSTALL.md) for native setup.

The example creates a 256 × 96 grayscale gradient, writes `leptonica-gradient.png` beside its executable, and prints the library and image paths. Open the PNG in an image viewer. Press Enter to close the console.

You can pass another output filename as the first command-line argument. Use a path representable in the Windows system code page.
